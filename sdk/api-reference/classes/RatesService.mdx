The `RatesService` class (accessed via `client.rates`) prices a delivery across every courier serving a route and returns the options side by side. You pick a quote, then hand it to [`fulfilOrder`](/sdk/api-reference/classes/OrdersService#fulfilorder) or [`createShipment`](/sdk/api-reference/classes/ShipmentsService#createshipment) to book it.

```typescript
import { TLDP } from '@tybrite-labs/tldp-sdk';

const client = new TLDP({ apiKey: 'tybrite_sk_test_...' });
```

## calculateRates

Returns priced quotes from every courier that serves the origin → destination route, ranked so you can present a choice to your customer (cheapest, fastest, highest tier, etc.).

<Note>
  **Two naming inconsistencies worth memorising:**
  1. The response field is **`quotes`** (not `rates`).
  2. Each quote's id is **`quote_id`** — but when you later fulfil with it, `fulfilOrder` / `createShipment` expect it under the key **`rate_quote_id`**. Read `quote.quote_id`, pass it as `rate_quote_id`.
</Note>

```typescript
const { quotes, meta } = await client.rates.calculateRates({
  requestBody: {
    origin: { city: 'Nairobi', zone: 'CBD' },        // zone optional
    destination: { city: 'Mombasa', zone: 'Nyali' }, // zone optional
    weight_kg: 1.2,
    declared_value: 4500,        // optional, for insurance/liability
    service_level: 'standard',   // optional: 'standard' | 'express' | ...
    special_flags: ['fragile'],  // optional
  },
});

// Show the cheapest option:
const cheapest = quotes.sort((a, b) => a.total_price - b.total_price)[0];
console.log(cheapest.courier_name, cheapest.total_price, cheapest.currency);

// Later, fulfil with it — note the key change:
// requestBody: { rate_quote_id: cheapest.quote_id }
```

**Returns** `{ quotes, meta }`. Each quote includes:

| Field | Description |
| :--- | :--- |
| `quote_id` | The quote's id. Pass it back as `rate_quote_id` to fulfil. |
| `courier_id` / `courier_name` | The courier behind this quote. |
| `courier_tier` | Service tier (e.g. Gold / Silver / Bronze). |
| `service_level` | The level priced (standard, express, …). |
| `total_price` / `currency` | What this delivery costs. |
| `estimated_delivery_hours` | Expected transit time in hours. |
| `estimated_delivery_date` | Expected delivery date. |
| `breakdown` | Line-by-line price components. |
| `valid_until` | When the quote expires — re-quote after this. |

<Warning>
  Quotes are time-bound. Once `valid_until` passes, re-run `calculateRates` before fulfilling; a stale `rate_quote_id` will be rejected.
</Warning>

## listZones

Lists the serviceable zones — the origin and destination cities the platform can route between. Use it to populate city/zone pickers in your checkout before quoting.

```typescript
const zones = await client.rates.listZones({});

for (const z of zones.zones ?? []) {
  console.log(z.city, z.zones);
}
```

**Returns** the catalogue of serviceable cities and their zones.
